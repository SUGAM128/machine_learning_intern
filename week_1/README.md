# Python Beginner Tasks

This repository contains basic Python exercises completed during my first week of internship.

## Topics Covered
- Variables and data types
- If-else conditions
- Loops
- Lists and dictionaries
- Functions
- File handling
- Basic use of NumPy, Pandas, Matplotlib and Scikit-learn

## How to Run

Make sure Python is installed.

Run the Python files using:

```bash
python filename.py
```

## Install Required Libraries

```bash
pip install -r requirements.txt
```
